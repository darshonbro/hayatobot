Slash Commands

Intuitive, modern Discord Application Commands at your fingertips.

Command Parameters Description
/role give member, role_id Assigns a role by snowflake ID, dispatches a personalized DM, and logs the action.
/role remove member, role_id Removes a role from a member and records an audit log.
/role info role_id Displays role position, members count, permissions, and configured DM description.
/dm-config set template Sets the server's reusable DM message template.
/dm-config preview role_id Previews how a DM template renders for a role without sending messages.
/dm-config description role_id, [description] Sets or clears a role-specific description for the {role_description} variable.
/dm-config variables — Lists all supported template variables and usage examples.
/config view — Displays current server template and configured descriptions.
/config reset — Restores factory default DM template via interactive confirmation buttons.
/audit recent [limit] Displays recent role actions, actors, and DM delivery outcomes.
/audit user member, [limit] Displays audit history affecting a specific user.

Privacy Policy

Effective Date: October 27, 2026 | Last Updated: October 27, 2026

1. Introduction

Your privacy is of paramount importance to us. This Privacy Policy explains how Hayato On Fire ("the Bot", "we", "our") collects, uses, stores, and protects information when you install and interact with our application on Discord.

By adding the Bot to your Discord guild or using its commands, you acknowledge and agree to the practices described in this policy, as well as the Discord Privacy Policy.

2. Information We Collect

We only collect the minimal technical data strictly necessary to provide role management, dynamic direct messaging, and audit logging features:

  • Discord Identifiers (Snowflakes): Guild IDs, User IDs, and Role IDs involved in slash commands or role assignments.
  • Display Names: The usernames or server nicknames of command executors and target members at the time an action is executed (solely recorded in audit logs).
  • Server Configurations: Custom DM templates configured by server administrators via /dm-config set and role-specific descriptions configured via /dm-config description.
  • Audit Logs & Delivery Metadata: Timestamps of role assignments or removals, action types (e.g. ROLE_ASSIGN, ROLE_REMOVE), and direct message delivery outcomes (e.g. SENT, FAILED).

What We DO NOT Collect: We do NOT monitor, read, or store server chat messages, message history, voice chat audio, email addresses, IP addresses, payment credentials, or personal identification details.

3. How We Use Collected Data

The collected data is exclusively used to:

  • Dynamically assign and remove roles requested by authorized server moderators.
  • Render personalized direct messages using the server's configured template (e.g. replacing {user} with the recipient's mention and {role} with the role name).
  • Provide server administrators with transparency through /audit recent and /audit user command queries.
  • Diagnose operational issues and verify that DMs were successfully delivered.

4. Data Storage and Security

All operational data is persisted in a secured relational database (SQLite / PostgreSQL) utilizing parameterized queries via SQLAlchemy 2.x to prevent injection vulnerabilities.

  • Guild Data Isolation: Every database entry is keyed and partitioned by guild_id. Data from one server is never shared, exposed, or accessible by another server.
  • Access Control: Database access is restricted to the bot process only. No unauthorized public or third-party access is permitted.

5. Third-Party Sharing

We do not sell, rent, monetize, or trade any user or server data to third parties, advertisers, or data brokers. Data is only transmitted to the Discord API as necessary to execute requested actions (such as adding roles or dispatching DMs).

6. Data Retention and Deletion (User Rights)

We adhere to data minimization principles:

  • Server Configurations: Persist until updated or reset by an administrator via /config reset or until the Bot is removed from the server.
  • Audit Logs: Maintained for operational logging and server moderation history. Older records are capped and pruned systematically.
  • Data Deletion Requests (GDPR / CCPA): If you are a server owner and wish to have all stored records for your guild deleted from our database, or if you are an individual user requesting the removal of your identifier from our logs, you may submit a deletion request to the contact provided below. All associated records will be purged within 30 days.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect operational or legal enhancements. Changes will be posted to this page with an updated "Last Updated" timestamp.

8. Contact & Privacy Inquiries

For privacy inquiries, questions regarding data handling, or to request data deletion, please contact us via:

  • Bot Application: Hayato On Fire
  • Developer Inquiries: Contact the Bot Developer through the official application contact on Discord.
